# Kennesaw Barber Shop

Static Astro marketing site for Kennesaw Barber Shop (3903 Jiles Rd #102, Kennesaw, GA). Cloned from the Parker Modern Classic Hair pattern, restyled old school suits and cigars. No backend yet; Book CTAs link to the shop's live Square booking page.

**Memory + hands:** start at [docs/WIKI.md](docs/WIKI.md).

```
npm install
npm run dev     # http://localhost:4321
npm run build   # static output in dist/
```
